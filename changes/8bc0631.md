# 8bc0631 — Sotto draws its own window, and five things found by running it on Windows

## Changes
- `SettingsWindow.qml` and `NotepadWindow.qml` are rooted in `SottoWindow`, a QQuickWindow port of the suite's frameless shell with the Windows native-frame takeover (Snap Layouts, edge resizing, maximise to the work area). The overlay HUD is untouched.
- `ModelManager` is rebuilt around a 45 s stall watchdog, three attempts each resuming with a `Range` header, a byte readout, a catalog-size progress fallback and a free-space precheck. Errors are shown once in the panel.
- `WhisperEngine` threads follow the machine (`clamp(hw-2, 2, 16)`, was capped at 8); `transcribed` carries the decode's elapsed time and `decodeProgress` reports a final pass.
- `TranscriptionSession` floors the partial cadence by the last decode's cost and drops stale partials, mid-decode, through ggml's abort callback.
- `App::statusText()` is the one source for the HUD label: "Transcribing… N left" → "Transcribing… NN%" → "Formatting…".
- The settings page prints `SOTTO_GPU_REASON`, baked by CMake, under the backend line.
- `SingleInstance` on Windows locks with a named mutex; the pipe only transports.
- `--quit` and `--stop` with nothing running exit instead of starting a background instance.

## Additions
- `src/ui/framelesswindow.{h,cpp}`, `qml/STitleBar.qml`, `qml/SWindowButton.qml`, `qml/SResizeEdges.qml`.
- Harness flags `SOTTO_OPEN=combo`, `SOTTO_STATE=finalizing`, and the headless downloader `SOTTO_DOWNLOAD=<model>` with `SOTTO_DOWNLOAD_SECONDS`.
- `src/ui` on the include path, because qmltyperegistrar records a `QML_ELEMENT` header by bare filename.

## Bug Fixes
- Drop-downs rendered empty rows: the delegate read `modelData[textRole]` (undefined for an object model) and `ItemDelegate`'s default padding left an eliding `Text` nothing to draw in. Now `control.textAt(index)` and `padding: 0`.
- A download that connected and delivered nothing sat at 0% with no message, because `downloadFinished` had no listener and `QFile::write`'s return was dropped.
- A second shortcut press while draining now calls `finishNow()`.
- Two Sotto instances could both run on Windows, each with a tray icon.

## Removals
- The 8-thread ceiling on decoding.
