# 8b892ee

**Changes**

- `.github/workflows/release.yml` triggers on `workflow_dispatch` only —
  a push to `main` no longer starts a release.
- The Windows completeness check keys on `MSSTORE_IDENTITY_NAME` rather
  than `PUBLISH_WINDOWS`, so shipping an `.msi` to R2 no longer requires
  a Microsoft Store listing.

None.

**Bug Fixes**

None — this is the fix for the coupling described above, landing here
as the owner/copy of `release.yml` rather than as a correction to prior
behaviour in this file.

The `push: branches: [main]` trigger.
