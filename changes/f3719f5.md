# f3719f5 — Sotto packaging, and a CI that finally compiles Windows

## Additions

- `.github/workflows/{ci,release}.yml` — Sotto had **no `.github/` directory**.
  Its CI sat in `docs/ci-workflow.yml` because the authoring session's git
  credential lacked the `workflow` scope, so nothing has ever built this repo
  automatically — and in particular nothing has ever compiled the Windows port.
- `cmake/MauvelyAppInfo.cmake`, `packaging/app.{desktop,metainfo.xml}.in`,
  `packaging/desktop-extra.ini`, the Flatpak manifest and build script, the MSI
  and MSIX builders, `scripts/package.{sh,ps1}`, `tools/render_icons.sh`.
- `SOTTO_STORE_BUILD` option.

## Bug Fixes

- **`--help` and `--version` printed nothing on Windows.** The target is
  `WIN32_EXECUTABLE` (GUI subsystem), so the process starts with no stdout.
  Both flags exited 0 having written nowhere — and the CI smoke test *is*
  `sotto --help`, so it would have passed while proving nothing.
  `AttachConsole(ATTACH_PARENT_PROCESS)` plus `freopen` onto `CONOUT$` fixes it;
  attaching alone does not rebind stdout, which is the part that is easy to miss.
- **`PER_USER` was missing from the packaging call.** Without it the `.msi`
  installs per-machine and every silent update raises a UAC prompt — the exact
  thing a per-user install exists to avoid.
- **`Categories=Utility;Accessibility;Audio;` is invalid.** `Audio` is a Main
  category the spec requires `AudioVideo` alongside; `desktop-file-validate`
  calls it an error that "will be fatal in the future".
- `KF6WindowSystem` was not platform-gated the way LayerShellQt is.

## Changes

- The binary lands in `build/bin/` like every sibling, not at the top of the
  build tree.
- `resources/icons/sotto.svg` → `packaging/app.svg`, with a configure-time copy
  back into `resources/icons/app.svg` for the embedded window and tray icon.
- `PROJECT_DESCRIPTION` no longer says "for Linux".
- README's packaging section rewritten for the four formats.

## Removals

- `docs/ci-workflow.yml`, `packaging/net.mauvely.sotto.app.desktop`,
  `resources/icons/sotto.ico` (now `app.ico`, generated).
