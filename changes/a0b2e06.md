# a0b2e06 — There are no screenshots here, and the build stops failing for their absence

## Bug fixes

### A check for something this app has never produced

`ci.yml` carried app-base's "Check the screenshots were rendered" step, which
fails the build when `shots/` is empty:

```
::error::no screenshots were rendered
```

It is always empty here. Sotto has no offscreen screenshot harness — no
`SOTTO_SHOT`, no `SOTTO_THEME`, none of the environment surface the other apps
use to grab their chrome — because there is no chrome to grab. The only
always-present window is a 440x64 HUD that stays hidden unless dictation is
running.

So the step failed every build in this repository, on both platforms, and it
failed on the one thing that was never coming. It is removed.

## Changes

A comment stands where the step was, saying that its absence is a decision and
naming the smoke run above it as this app's equivalent guarantee. The workflow
is a copy of app-base's and will be re-copied; without that note the next copy
puts the step back and the next person spends the same hour on it.
